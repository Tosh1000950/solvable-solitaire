# 必ず解けるソリティア（Guaranteed Solvable Solitaire）

詰む配布を排除したクロンダイク・ソリティアです。**すべての配布に解法が存在します**（1枚引き専用）。難易度は3段階あります。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（PC／スマホ対応、単一ファイル・外部素材なし）。

- 山札クリック／タップで1枚めくる
- 場札は赤黒交互に数字が1つずつ小さくなるよう重ねる。空いた列には K
- 組札には同じマークを A から順に重ねる
- ドラッグ＆ドロップ、クリック選択→置き先クリック、ダブルクリックで自動移動
- 「一手戻す」「同じ配布でやり直し」「ヒント」「自動回収（全カードが表向きのとき）」つき

## 対応言語

日本語 / English / 简体中文（簡体字） / Español / Русский / Português (Brasil) / हिन्दी の7言語に対応しています。画面上部のセレクトで切り替えでき、選択はブラウザに保存されます。初回はブラウザの言語設定から自動で選ばれます（対応外の言語の場合は英語）。

## 難易度と保証の仕組み

- **ふつう／むずかしい**：通常のランダム配布から、判定用ソルバー（探索で解法を探すプログラム）が実際に解法を見つけ、その解法を1手ずつ再生して勝てることまで確認できた配布だけを集めた、検証済みシードプールを使います。難易度の差は、ソルバーが解法を見つけるのに要した探索量（ふつう＝小さな探索で発見／むずかしい＝大きな探索が必要だった）。「むずかしい」は遠回りの手や組札から戻す手が必要になることがあります。
- **かんたん（練習）**：逆生成方式。先に「組札へ A→2→…→K と送る解き方」を決め、その順に剥がしていけるよう配置するため、何も考えずに進めても解けます。

実測（ランダム配布40件）：「組札へ置けるものを置くだけ」の何も考えない戦略は、通常配布では52枚中2〜15枚進んだところで止まります。対して「かんたん」の配布は同戦略で200件中200件クリアできました。難易度は体感ではなく、この差に基づいています。

## 検証

- `test_core.js`：「かんたん」の逆生成配布を1,000件生成し、全件が解法シミュレーションでクリアできること、配布構造が正しいことを確認
- `test_pools.js`：ゲーム本体の配布ロジックが検証用実装と一致することを確認
- `verify_pools.js`：プール全件をソルバーで解き直し、解法の再生検証が全件通ることを確認
- `test_ui.js`：実際のUIコードを jsdom 上で動かし、各難易度の解法どおりに操作してクリアできることを確認
- `test_drag.js`：実ブラウザ（Chrome headless）でドラッグを再現し、ドラッグ中に元のカードが隠れて下のカードが見えること、ゴーストが掴んだ位置でカーソルに追従すること、ドロップで手が成立することを確認
